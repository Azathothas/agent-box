# Start here, on branch ephemeral-errand-sandbox-research

This branch holds research, not product code. A session that continues it
reads one file first:

    research/errand-sandbox/next-session.md

That file stands alone. It says how to clone this branch, what was measured
and on which host, the host conditions that broke something and their
fixes, and the corrected prompt for the errand-box work.

The rest of the tree is branch `main` of agent-box, unchanged. Its AGENTS.md
describes agent-box itself, not this research.
